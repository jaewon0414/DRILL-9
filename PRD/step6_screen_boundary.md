# 6단계 PRD: 화면 경계 처리

## 목표

소년이 화면 경계에 닿으면 더 나아가지 않는다.

## 요구사항

- 소년은 상하좌우 어느 쪽으로도 화면 밖으로 나가지 않는다.
- 경계에 닿은 채 키를 계속 눌러도 위치가 변하지 않는다.
- 한쪽 경계에 막혀 있어도 다른 축으로는 움직일 수 있다. (예: 오른쪽 벽에 붙은 채 위아래 이동)
- 반대 방향 키를 누르면 바로 경계에서 벗어난다.

## 구현 방법

프레임 한 칸은 100×100이지만 실제 소년 그림은 칸보다 작다.
칸 크기(절반 50)로 막으면 벽에 닿기 전에 멈춘 것처럼 보이므로, 소년 그림 크기에 맞춘 여백을 쓴다.

시트의 투명하지 않은 픽셀을 재 보면, 소년은 칸 중심에서 좌우로 최대 34픽셀, 위로 43픽셀, 아래로 37픽셀까지 그려져 있다.
이 값을 조금 넉넉하게 올려 여백으로 쓴다.

| 상수 | 뜻 | 값 |
|---|---|---|
| `HALF_W` | 소년 중심에서 좌우 끝까지 거리 | 35 |
| `HALF_H` | 소년 중심에서 위아래 끝까지 거리 | 45 |

- 이동한 뒤 좌표를 범위 안으로 되돌린다. pico2d의 `clamp(최솟값, 값, 최댓값)`을 쓴다.

| 좌표 | 최솟값 | 최댓값 |
|---|---|---|
| `x` | 35 | 800 - 35 = 765 |
| `y` | 45 | 600 - 45 = 555 |

- 이동을 막지 않고 이동 후에 좌표를 고치므로, 경계에 닿아 있어도 `dir_x`, `dir_y`는 그대로다. 그래서 벽에 대고 달리는 동안에는 달리기 그림이 계속 나온다.

## 확인 방법

| 완료 기준 | 확인 방법 |
|---|---|
| 네 방향 모두 화면 밖으로 나가지 않는다 | 방향키를 하나씩 끝까지 누른다 |
| 경계에서 키를 계속 눌러도 위치가 그대로다 | 벽에 닿은 뒤 계속 누른다 |
| 벽에 붙은 채 다른 축으로 움직인다 | 오른쪽 벽에서 오른쪽을 누른 채 위를 누른다 |
| 반대 키를 누르면 바로 벗어난다 | 벽에서 반대 방향키를 누른다 |
