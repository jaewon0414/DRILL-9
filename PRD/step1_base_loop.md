# 1단계 PRD: 기본 게임 루프

## 목표

배경과 소년이 화면에 보이고 정상적으로 종료되는 가장 작은 프로그램을 만든다. 이후 단계는 모두 이 루프 위에 기능을 하나씩 더하는 방식으로 진행한다.

## 요구사항

프로그램을 실행하면 800×600 크기의 캔버스가 열린다. 캔버스 중앙에는 `TUK_GROUND.png`를 그린다. 이 이미지는 1280×1024로 캔버스보다 크기 때문에 가운데 부분만 보인다. 그 위에 `animation_sheet.png`의 소년을 화면 중앙인 (400, 300)에 그리고, 프레임 8장을 0.05초 간격으로 반복해서 재생한다. ESC 키를 누르거나 창 닫기 버튼을 누르면 프로그램이 끝난다.

## 구현 방법

상태는 변수 네 개로 관리한다. `running`은 게임 루프를 계속 돌지를 나타내며 처음 값은 `True`다. `x`와 `y`는 소년의 위치이며 처음 값은 400과 300이다. `frame`은 현재 프레임 번호로 0부터 7까지 바뀌며 처음 값은 0이다.

입력은 `handle_events()` 함수에서 처리한다. 이 함수는 `get_events()`로 받은 이벤트를 모두 확인해서, 창 닫기 이벤트나 ESC 키 이벤트가 있으면 `running`을 `False`로 바꾼다. 함수 안에서 바깥 변수를 바꿔야 하므로 `global running` 선언이 필요하다.

루프는 한 번 돌 때마다 화면을 지우고, 배경과 소년을 그리고, 화면을 갱신하고, 입력을 처리하고, 프레임 번호를 하나 올린 뒤 0.05초를 기다린다.

## 이 단계에서 하지 않는 것

이동과 동작 전환은 아직 넣지 않는다. 소년은 제자리에서 `bottom`이 100인 오른쪽 달리기 줄을 임시로 재생한다.

## 확인 방법

`py -3.14 drill09.py`로 실행했을 때 오류 없이 800×600 창이 열리는지 확인한다. 배경 위 중앙에 소년이 보이고 프레임이 계속 바뀌는지 화면에서 확인한다. 마지막으로 ESC 키와 창 닫기 버튼을 각각 눌러 프로그램이 끝나는지 확인한다.
