# 1단계 PRD: 기본 게임 루프

## 목표

배경과 소년이 화면에 보이고, 정상적으로 종료되는 가장 작은 프로그램을 만든다.
이후 단계는 모두 이 루프 위에 기능을 하나씩 더한다.

## 요구사항

- 800×600 캔버스를 연다.
- `TUK_GROUND.png`를 캔버스 중앙에 그린다. 이미지가 1280×1024로 캔버스보다 커서 가운데 부분만 보인다.
- `animation_sheet.png`의 소년을 화면 중앙 (400, 300)에 그린다.
- 프레임 8장을 0.05초 간격으로 반복 재생한다.
- ESC 키 또는 창 닫기 버튼으로 종료한다.

## 구현 방법

| 변수 | 역할 | 처음 값 |
|---|---|---|
| `running` | 게임 루프를 계속 돌지 여부 | `True` |
| `x`, `y` | 소년의 위치 | 400, 300 |
| `frame` | 현재 프레임 번호 (0~7) | 0 |

- `handle_events()`에서 `get_events()`로 받은 이벤트를 모두 확인해 `running`을 바꾼다.
- 루프 한 번의 순서: 화면 지우기 → 배경 → 소년 → 화면 갱신 → 입력 처리 → 프레임 증가 → 0.05초 대기

## 이 단계에서 하지 않는 것

- 이동과 동작 전환. 소년은 제자리에서 오른쪽 달리기 줄(`bottom = 100`)을 임시로 재생한다.

## 확인 방법

| 완료 기준 | 확인 방법 |
|---|---|
| 오류 없이 800×600 창이 열린다 | `py -3.14 drill09.py` 실행 |
| 배경 위 중앙에 소년이 보이고 프레임이 바뀐다 | 화면 관찰 |
| ESC와 창 닫기로 종료된다 | 각각 눌러 본다 |
