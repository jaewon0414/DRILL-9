# 2단계 PRD: 좌우 이동

## 목표

좌우 방향키를 누르고 있는 동안 소년이 그 방향으로 계속 움직인다.

## 요구사항

- 오른쪽 방향키를 누르고 있으면 오른쪽으로, 왼쪽 방향키를 누르고 있으면 왼쪽으로 움직인다.
- 키를 떼면 멈춘다.
- 좌우 키를 함께 누르면 멈추고, 그중 하나만 떼면 남은 키 방향으로 움직인다.
- 이동 속도는 프레임당 5픽셀이다.

## 구현 방법

키를 누른 순간에만 좌표를 바꾸면 한 번 누를 때 한 번만 움직인다.
그래서 이벤트에서는 이동 방향만 기록하고, 실제 이동은 루프에서 매 프레임 한다.

| 변수 | 역할 | 값 |
|---|---|---|
| `dir_x` | 좌우 이동 방향 | -1 왼쪽, 0 정지, 1 오른쪽 |

| 이벤트 | 오른쪽 방향키 | 왼쪽 방향키 |
|---|---|---|
| `SDL_KEYDOWN` | `dir_x += 1` | `dir_x -= 1` |
| `SDL_KEYUP` | `dir_x -= 1` | `dir_x += 1` |

- 값을 대입하지 않고 더하고 빼는 이유: 두 키를 함께 눌렀을 때 0이 되고, 하나를 떼면 남은 키의 값이 그대로 남는다.
- 루프에서 매 프레임 `x += dir_x * 5`를 한다.

## 이 단계에서 하지 않는 것

- 방향에 맞는 그림. 왼쪽으로 가도 오른쪽 달리기 그림이 나온다. (4단계)
- 화면 경계 처리. 소년이 화면 밖으로 나갈 수 있다. (6단계)

## 확인 방법

| 완료 기준 | 확인 방법 |
|---|---|
| 키를 누르고 있는 동안 계속 움직인다 | 좌우 방향키를 각각 길게 누른다 |
| 키를 떼면 멈춘다 | 키를 뗀 뒤 위치가 그대로인지 관찰 |
| 좌우를 함께 누르면 멈추고, 하나를 떼면 남은 방향으로 간다 | 오른쪽을 누른 채 왼쪽을 누르고, 오른쪽만 뗀다 |
