# 3단계 PRD: 상하 이동

## 목표

위아래 방향키로도 소년이 움직이게 해서 상하좌우 이동을 모두 완성한다.

## 요구사항

위 방향키를 누르고 있으면 소년이 위로, 아래 방향키를 누르고 있으면 아래로 움직인다. 좌우 키와 함께 누르면 대각선으로 움직인다. 위아래 키를 함께 누르면 세로로는 멈춘다. 이동 속도는 좌우와 같은 프레임당 5픽셀이다.

## 구현 방법

2단계에서 만든 `dir_x`와 같은 방식으로 세로 방향을 기록하는 변수 `dir_y`를 하나 더 둔다. 값이 -1이면 아래로 이동 중, 0이면 정지, 1이면 위로 이동 중이라는 뜻이다. pico2d 캔버스는 위로 갈수록 y가 커지기 때문에 위쪽을 +1로 정했다.

위 방향키를 누르면 `dir_y`에 1을 더하고 떼면 1을 뺀다. 아래 방향키는 반대로 누르면 1을 빼고 떼면 1을 더한다. 루프에서는 매 프레임 `y += dir_y * 5`를 실행한다.

가로와 세로를 서로 다른 변수로 관리하기 때문에 두 방향의 키를 함께 누르면 x와 y가 동시에 바뀌어 대각선 이동이 된다.

## 이 단계에서 하지 않는 것

방향에 맞는 그림은 4단계에서, 화면 경계 처리는 6단계에서 다룬다.

## 확인 방법

위 방향키와 아래 방향키를 각각 길게 눌러 위아래로 움직이는지 확인한다. 오른쪽 키와 위 키를 함께 눌러 대각선으로 움직이는지 확인한다. 위 키를 누른 채 아래 키를 눌러 세로로 멈추는지 확인한다.
