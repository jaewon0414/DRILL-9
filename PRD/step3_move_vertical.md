# 3단계 PRD: 상하 이동

## 목표

위아래 방향키로도 소년이 움직여 상하좌우 이동이 모두 된다.

## 요구사항

- 위 방향키를 누르고 있으면 위로, 아래 방향키를 누르고 있으면 아래로 움직인다.
- 좌우 키와 함께 누르면 대각선으로 움직인다.
- 위아래 키를 함께 누르면 세로로는 멈춘다.
- 이동 속도는 좌우와 같은 프레임당 5픽셀이다.

## 구현 방법

2단계의 `dir_x`와 같은 방식으로 세로 방향 변수를 하나 더 둔다.

| 변수 | 역할 | 값 |
|---|---|---|
| `dir_y` | 상하 이동 방향 | -1 아래, 0 정지, 1 위 |

| 이벤트 | 위 방향키 | 아래 방향키 |
|---|---|---|
| `SDL_KEYDOWN` | `dir_y += 1` | `dir_y -= 1` |
| `SDL_KEYUP` | `dir_y -= 1` | `dir_y += 1` |

- pico2d 캔버스는 위로 갈수록 y가 커지므로 위쪽이 +1이다.
- 루프에서 매 프레임 `y += dir_y * 5`를 한다.

## 이 단계에서 하지 않는 것

- 방향에 맞는 그림 (4단계), 화면 경계 처리 (6단계)

## 확인 방법

| 완료 기준 | 확인 방법 |
|---|---|
| 위아래 키로 위아래로 움직인다 | 위, 아래 방향키를 각각 길게 누른다 |
| 좌우 키와 함께 누르면 대각선으로 움직인다 | 오른쪽과 위를 함께 누른다 |
| 위아래를 함께 누르면 세로로 멈춘다 | 위를 누른 채 아래를 누른다 |
