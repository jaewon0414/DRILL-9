# 5단계 PRD: IDLE 애니메이션

## 목표

소년이 멈춰 있을 때는 달리기가 아니라 IDLE 애니메이션을 보여 준다.

## 요구사항

- 가로와 세로 모두 움직이지 않을 때를 IDLE 상태로 본다.
- IDLE 상태에서는 마지막으로 바라본 방향의 IDLE 그림을 보여 준다.
- 좌우 키를 함께 눌러 멈춘 경우도 IDLE이다.
- 프로그램을 시작한 직후에는 오른쪽을 바라보는 IDLE이다.

## 구현 방법

- `dir_x == 0 and dir_y == 0`이면 IDLE, 아니면 달리기다.
- 4단계의 `face`와 합쳐서 그릴 줄을 정한다.

| 상태 | `face` | `bottom` |
|---|---|---|
| IDLE | 1 (오른쪽) | 300 |
| IDLE | -1 (왼쪽) | 200 |
| 달리기 | 1 (오른쪽) | 100 |
| 달리기 | -1 (왼쪽) | 0 |

- IDLE 줄도 8프레임이므로 `frame`은 지금처럼 0~7을 그대로 쓴다.

## 확인 방법

| 완료 기준 | 확인 방법 |
|---|---|
| 시작 직후 오른쪽을 보는 IDLE이 나온다 | 실행하고 키를 누르지 않는다 |
| 왼쪽으로 가다 멈추면 왼쪽을 보는 IDLE이 나온다 | 왼쪽 방향키를 눌렀다 뗀다 |
| 위아래로 가다 멈춰도 바라보던 방향의 IDLE이 나온다 | 왼쪽 → 위 순서로 움직였다가 멈춘다 |
| 좌우를 함께 누르면 IDLE이 나온다 | 좌우 방향키를 함께 누른다 |
